Promise Tracker Mobile Capture

Install Promise Tracker on Android so it can appear in your phone's Share menu. Then you can share an SMS or WhatsApp message directly into Promise Tracker for AI promise detection.

1. Open this page in Chrome on Android.
2. Tap Chrome's menu and choose Install app or Add to Home screen.
3. Open Messages or WhatsApp, select/share a message, and choose Promise Tracker from the Share sheet.
4. Promise Tracker will open the shared text and let you analyze it before adding anything.

Open Promise Tracker

Android share-target support requires the PWA to be installed. iPhone does not currently offer the same PWA share-target behavior, so iPhone users can use copy/paste capture for now.
